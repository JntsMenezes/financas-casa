# Finanças da Casa

App simples (PWA) para controlar entradas e saídas da casa, com saldo realizado e previsto, contas fixas e parcelas. Os dados ficam no Supabase, protegidos por login e por regras de acesso (RLS).

- `index.html`, `app.js`: o app
- `config.js`: URL e chave publicável do Supabase
- `supabase/schema.sql`: estrutura do banco
